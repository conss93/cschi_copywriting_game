# 🖋️ 카피퀘스트: 글빨골목

카피라이터·온라인 마케터 지망생을 위한 **2D 탑다운 RPG형 카피라이팅 연습 게임**입니다.

> 퇴사 300일차, 통장 잔고 84,000원.
> 이 동네 '글빨골목'에는 이상한 법칙이 있다 —
> 손님의 발길을 멈추게 하는 글을 쓰는 가게만 살아남는다.
> 당신은 노트북 하나 들고 이 골목에 도착한 신입 카피라이터다.

## 실행 방법

빌드 도구, 설치, 서버가 전혀 필요 없습니다.

1. 저장소를 다운로드(또는 clone)
2. `index.html`을 브라우저로 열기 — 끝!

GitHub Pages에 올리면 링크 하나로 누구나 플레이할 수 있습니다.

## 조작법

| 입력 | 동작 |
|------|------|
| 방향키 / WASD | 이동 |
| Space / Enter | 대화·상호작용 |
| ESC | 창 닫기 |
| 모바일 | 화면의 D패드 + A 버튼 |

`❗` 표시가 뜬 NPC에게 다가가 말을 걸면 의뢰(퀘스트)를 받을 수 있습니다.

## 🤖 Claude API 연동 (선택)

게임 내 **⚙️ 설정**에서 [Claude API 키](https://console.anthropic.com/)를 입력하면:

- **NPC 잡담**: 각 NPC가 자기 성격(무뚝뚝한 빵집 사장, 하이텐션 카페 사장, 깐깐한 대행사 팀장…)대로 실제 AI와 자유 대화
- **AI 첨삭·채점**: 제출한 카피를 NPC의 말투로 첨삭하고, 점수·개선 예시·팁을 JSON 구조화 출력으로 반환

키는 브라우저 localStorage에만 저장되며 Anthropic API 호출 외에는 어디에도 전송되지 않습니다.
키가 없으면 규칙 기반 채점(글자 수·숫자 활용·금지어 등)으로 동작합니다.

## 게임 구성

| 요소 | 설명 |
|------|------|
| 스토리 | 대형몰 '몰팩토리'의 골목 재개발에 맞서 카피로 골목을 지키는 5막 구성 (튜토리얼 → 골목 살리기 → 위기 → 축제 준비 → 최종 슬로건 대결) |
| 맵 3개 | 마을(글빨골목) + 시장길(스토리로 개방) + 실내 사무실(골목기획), 출입구로 이동 |
| NPC 9명 | 각자 성격 프롬프트 보유 — 김소금·이보틀·채리·봉대표·정진심·오팀장 + 시장길 한송이·황붕어·매니저Q(라이벌) |
| 메인 퀘스트 10개 | 헤드라인 → 혜택 번역 → CTA → 타겟팅 → 사회적 증거 → 이메일 제목 → 긴급성 → 스토리텔링 → 압축 → 포지셔닝(최종 대결) |
| 서브 퀘스트 3개 | 꽃 정기구독 인스타 / 붕어빵 현수막 / 릴스 훅 — 포인트 벌이용 선택 의뢰 |
| 길잡이 | 화면 상단 목표 바 + 스토리 컷신이 다음 행동을 안내 (튜토리얼 내장) |
| 성장 | XP·레벨 + 포인트(P) 이중 재화 |
| 상점 | 편의점 '카피24' — 힌트 아이템(아메리카노), 경험치 부스트(만년필), 코스튬 3종 |
| 업적 | 메달 16종 (스토리 진행·점수·수집·잡담 등) |
| 저장 | localStorage 자동 저장, 타이틀 화면에서 이어하기 |

## 프로젝트 구조

```
index.html      # 화면 마크업 (타이틀/인트로/HUD/캔버스/모달들)
css/style.css   # 스타일 (모바일 최적화 포함)
js/data.js      # 데이터 — 인트로, NPC(성격 프롬프트), 스토리 이벤트, 퀘스트, 상점, 업적
js/map.js       # 멀티맵 타일맵 + 충돌 + 출입구(워프) 정의 (로드 시 자체 검증)
js/sprites.js   # 프로시저럴 픽셀아트 (캐릭터, 실내외 타일, 간판)
js/ai.js        # Claude API 연동 (NPC 대화 + 구조화 출력 채점, 폴백 포함)
js/ui.js        # DOM 오버레이 (타이틀, 스토리 컷신, 대화창, 퀘스트, 상점 등)
js/game.js      # 엔진 (상태, 스토리 진행, 입력, 맵 전환, 렌더링)
```

### 콘텐츠 추가하기

- **새 퀘스트**: `js/data.js`의 `QUESTS` 배열에 객체 추가 (`npcId`로 의뢰인 지정, `checks`는 폴백 채점 규칙)
- **새 NPC**: `NPCS` 배열에 추가 — `persona`가 AI 성격, `x/y`는 타일 좌표(통행 가능 칸), `sprite`는 `js/sprites.js`의 프리셋
- **새 아이템**: `SHOP_ITEMS`에 추가 (`consumable`/`passive`/`outfit`)
