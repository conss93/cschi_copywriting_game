# 🖋️ 카피퀘스트: 잉크의 대륙

카피라이터·온라인 마케터를 꿈꾸는 사람들을 위한 **RPG형 카피라이팅 연습 게임**입니다.

> 대침묵 이후, 이 대륙에서는 사람의 '주목'이 곧 화폐가 되었다.
> 말로 발길을 멈추게 하는 자는 부유해지고, 그러지 못한 가게는 조용히 잊혀 사라진다.
> 당신은 워드스미스 길드에 갓 등록한 견습생이다.

## 실행 방법

빌드 도구, 설치, 서버가 전혀 필요 없습니다.

1. 이 저장소를 다운로드(또는 clone)
2. `index.html`을 브라우저로 열기 — 끝!

GitHub Pages에 올리면 바로 웹에서 플레이할 수 있습니다.
(저장소 Settings → Pages → 브랜치 선택 → 루트 폴더)

## 게임 구성

| 요소 | 설명 |
|------|------|
| 퀘스트 | 헤드라인, 혜택 번역, CTA, 타겟팅, 사회적 증거, 긴급성, 스토리텔링 등 실전 카피라이팅 과제 9개 (3개 장 구성) |
| 자동 평가 | 글자 수, 숫자 활용, 금지어 회피 등 규칙 기반 채점 → 점수만큼 XP 획득 |
| 자가 점검 | 규칙으로 잴 수 없는 부분은 체크리스트로 스스로 점검 |
| 성장 | XP를 모아 레벨 업 (다음 레벨 필요 XP = 레벨 × 200) |
| 업적 메달 | 첫 퀘스트, 장 클리어, 만점 통과, 퇴고의 장인 등 8종 |
| 저장 | localStorage 자동 저장 — 브라우저를 닫아도 이어서 플레이 |

## 프로젝트 구조

```
index.html          # 화면 마크업 (인트로 / 마을 허브 / 퀘스트)
css/style.css       # 스타일
js/quests.js        # 퀘스트 데이터 — 여기에 객체를 추가하면 새 퀘스트 생성
js/achievements.js  # 업적 메달 정의 — condition 함수로 획득 조건 기술
js/game.js          # 게임 엔진 (상태 관리, 화면 전환, 평가, 보상)
```

### 새 퀘스트 추가하기

`js/quests.js`의 `QUESTS` 배열에 객체 하나를 추가하면 됩니다.

```js
{
  id: "q10",                 // 고유 id
  chapter: 3,                // 소속 장
  title: "퀘스트 제목",
  client: "의뢰인 이름",
  briefing: "세계관 속 상황 설명",
  mission: "실제 카피라이팅 과제",
  lesson: "완료 후 보여줄 카피라이팅 원칙",
  example: "모범 답안 예시",
  minLength: 5,              // 최소 글자 수
  checks: [                  // 자동 채점 규칙
    { desc: "규칙 설명", test: (t) => t.length <= 25 },
  ],
  selfChecks: ["자가 점검 질문"],
  xp: 100,                   // 만점 시 획득 경험치
}
```
